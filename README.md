# Python UV Project Template

A Copier template for Python projects.

## Features
- UV-based dependency management

## Usage

To create a new project from this template, run:

```bash
copier copy gh:gauthamchettiar/copier-uv <destination-folder>
```

or if you have a local copy of the template:

```bash
copier copy /path/to/copier-uv <destination-folder>
```

## Questions

When you run the copy command, you'll be asked the following questions:

1. **What is your project name?**
   - Default: `my-project`
   - Example: `my-awesome-project`

2. **What is the Python package name (slug)?**
   - Default: Auto-generated from project name (lowercase, underscores)
   - Example: `my_awesome_project`

3. **Project description**
   - Default: `Add your description here`
   - Example: `A wonderful Python package for doing amazing things`

4. **Author name**
   - Default: `Your Name`
   - Example: `John Doe`

5. **Author email**
   - Default: `your.email@example.com`
   - Example: `john.doe@example.com`

6. **Minimum Python version**
   - Default: `3.10`
   - Choices: `3.10`, `3.11`, `3.12`, `3.13`, `3.14`

7. **Choose a license**
   - Default: `MIT`
   - Choices: `MIT`, `Apache-2.0`, `BSD-3-Clause`, `GPL-3.0`, `MPL-2.0`

8. **Copyright year**
   - Default: `2026`
